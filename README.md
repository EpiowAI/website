# Epiow Limited - Official Website

Leading AI application development company in the United Kingdom.

## 🚀 Tech Stack

- **Framework**: SolidJS
- **Runtime**: Bun
- **Styling**: PandaCSS
- **Linter/Formatter**: Biome
- **Deployment**: Vercel

## 📦 Installation

```bash
bun install
```

## 🛠️ Development

```bash
bun run dev
```

Visit [http://localhost:3000](http://localhost:3000)

## 🏗️ Build

```bash
bun run build
```

## 🚢 Deployment

Deploy to Vercel:

```bash
bunx vercel --prod
```

## 📋 Available Scripts

- `bun run dev` - Start development server
- `bun run build` - Build for production
- `bun run preview` - Preview production build
- `bun run prepare` - Generate PandaCSS styles
- `bun run format` - Format code with Biome
- `bun run lint` - Lint and auto-fix code
- `bun run check` - Check code without fixing

## 🎨 SEO & Assets

### Favicon
The site uses an SVG favicon located at `/public/favicon.svg`.

### OG Image
For optimal social media sharing, convert `/public/og-image.svg` to PNG:

```bash
# Using any SVG to PNG converter
# Recommended size: 1200x630px
```

Then update `index.html` to reference `/og-image.png` instead of `/og-image.svg`.

### Sitemap
Update the sitemap at `/public/sitemap.xml` with your production domain.

### Robots.txt
Update the robots.txt at `/public/robots.txt` with your production domain.
